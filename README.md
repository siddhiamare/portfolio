\# Siddhi Amare — Portfolio



A personal portfolio site showcasing my projects, skills, and experience as a Python Developer and Full-Stack Engineer.



\*\*Live site:\*\* \[siddhiamare.github.io/portfolio](https://siddhiamare.github.io/portfolio/)



\## About



This is a single-page, dark-themed portfolio built to highlight my work in Python, Django, Flask, machine learning, and cloud infrastructure (AWS). It includes:



\- \*\*Hero section\*\* — intro and rotating role titles

\- \*\*Selected Work\*\* — featured projects (ML apps, a serverless AWS platform, a full-stack currency converter)

\- \*\*Notes\*\* — short write-ups on problems I solved while building

\- \*\*Explorations\*\* — a visual overview of the tools and platforms I work with

\- \*\*Stats\*\* — a few numbers from my recent projects

\- \*\*Contact\*\* — how to reach me



\## Tech Stack



\- \*\*React\*\* + \*\*TypeScript\*\* + \*\*Vite\*\* — core app and build tooling

\- \*\*Tailwind CSS\*\* — styling and design system

\- \*\*GSAP\*\* — scroll-driven and entrance animations

\- \*\*Framer Motion\*\* — component-level animation and transitions

\- \*\*hls.js\*\* — adaptive video streaming for the background video



\## Getting Started



Clone the repo and install dependencies:



```bash

git clone https://github.com/siddhiamare/portfolio.git

cd portfolio

npm install

```



Run the local dev server:



```bash

npm run dev

```



Build for production:



```bash

npm run build

```



\## Deployment



This site auto-deploys to \*\*GitHub Pages\*\* via GitHub Actions on every push to `main`. The workflow is defined in \[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) — it builds the Vite project and publishes the output to Pages automatically, so no manual deploy step is needed.
